# Dokumentasi development aplikasi

Pilih subfolder modul melalui [peta dokumentasi](../README.md). Catatan di sini menjelaskan implementasi, alur aplikasi, dan validasi. Catatan skema serta migrasi dipisahkan ke [dokumentasi database](../database/); panduan pengguna ada di [penggunaan](../penggunaan/).

Penataan ini tidak mengubah route, izin, atau logika aplikasi. Tidak ada perubahan skema database.
