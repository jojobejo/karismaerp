# Tombol logout pada halaman portal

Tanggal: 21 Oktober 2026

## Perubahan

Halaman portal kini menampilkan tombol **Logout** di bar navigasi atas, termasuk bagi pengguna non-admin. Tombol memakai route logout yang sudah tersedia, sehingga sesi berakhir dan pengguna kembali ke halaman login.

## File

- `application/views/portal/index.php`

Tidak ada perubahan database. Sintaks PHP diperiksa; uji klik melalui browser belum dilakukan.
