# Dropdown Departemen pada Form User

Form tambah dan ubah user mengambil pilihan dari `tb_departemen` melalui referensi master organisasi. Nilai yang disimpan ke `tb_karyawan.departemen` adalah nama departemen agar tetap kompatibel dengan pencarian dan filter user yang sudah ada.

Untuk menambahkan pilihan, buka **User Management > Setting Master Kantor > Departemen** lalu simpan nama departemen. Perubahan ini tidak mengubah skema database.
