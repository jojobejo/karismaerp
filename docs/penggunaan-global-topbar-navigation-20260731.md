# Penggunaan - Global Topbar Navigation

Tanggal: 2026-07-31

## Cara Pakai

Topbar biru tampil otomatis pada halaman aplikasi yang memakai layout ERP utama dan modul KIU PO/Purchasing.

## Elemen Topbar

- Ikon kotak kiri: membuka/menutup sidebar pada halaman yang memiliki sidebar.
- Teks `Dashboard`: membuka halaman dashboard.
- Label kanan: menampilkan departemen user dari session, misalnya `PURCHASING`.
- Ikon logout kanan: keluar dari aplikasi melalui route `logout`.

## Pengecualian

Topbar tidak ditambahkan ke halaman portal dan tidak dipakai pada layout printout/cetak dokumen. Saat halaman biasa dicetak lewat browser, topbar juga disembunyikan oleh CSS print.
