# Penggunaan - ICS ICSPo Header Purchasing dan Status Data

Tanggal: 2026-07-21

## Route

`ics/icspo`

## Cara Cek

1. Login sebagai user Purchasing/Admin PO/Admin.
2. Buka route `ics/icspo`.
3. Lihat tabel Purchasing.
4. Header tabel akan tampil sebagai:

`Tgl LPB | No LPB | No PO | Nama Supplier | Grand Total LPB | LPB Status | Status Data | #`

## Status Data

Kolom `Status Data` menampilkan tiga icon:

- Invoice
- Pajak/Faktur
- Afirmasi harga

Icon hijau berarti data sudah lengkap.

Icon abu-abu berarti data belum lengkap.

Gunakan tombol `#` untuk masuk ke detail LPB jika perlu melengkapi invoice, pajak, atau afirmasi harga.
