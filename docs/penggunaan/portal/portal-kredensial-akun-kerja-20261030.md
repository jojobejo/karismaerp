# Panduan Kredensial Akun Kerja Portal

1. Admin mengimpor akun kerja dari halaman Integrasi SSO dan menetapkan akun untuk pengguna serta aplikasi yang sesuai.
2. Pengguna login ke Portal seperti biasa.
3. Pada kartu aplikasi dengan status **Akun kerja tersedia**, username dan password akun aplikasi klien ditampilkan. Gunakan **Mulai Bekerja** untuk membuka aplikasi.
4. Jika password tidak dapat ditampilkan, hubungi admin untuk memeriksa penetapan akun dan kunci enkripsi.

Yang ditampilkan adalah password akun kerja aplikasi klien, bukan password login Portal. Jaga kerahasiaan kredensial tersebut.
