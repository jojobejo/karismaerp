# Penggunaan - ICS ICSPo Restore Tab Logistik

Tanggal: 2026-07-21

## Route

`ics/icspo`

## Cara Cek

1. Buka route `ics/icspo`.
2. Pilih tab `Logistik`.
3. Pastikan header tabel Logistik kembali menampilkan:

`No PO | Tgl Transaksi | Kode Supplier | Nama Supplier | Total Barang Order | Total Barang Diterima | Progress | Input Terakhir | Status | #`

4. Klik tombol `Detail` pada kolom `#`.
5. Sistem membuka detail PO melalui route `ics/detail_po`.

Tab `Purchasing` tetap memakai tampilan baru dengan `Grand Total LPB`, `LPB Status`, dan `Status Data`.
