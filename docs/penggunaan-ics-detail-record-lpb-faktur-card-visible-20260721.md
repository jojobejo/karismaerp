# Penggunaan - ICS Detail Record LPB Faktur Card Visible

Tanggal: 2026-07-21

## Route

`ics/detail_record_lpb`

## Cara Melihat Faktur Pajak

1. Buka detail record LPB dari menu ICS PO.
2. Pilih salah satu LPB.
3. Lihat header detail LPB.

Header detail menampilkan kembali:

```text
Faktur Pajak
Tanggal Terbit Faktur
```

Jika faktur pajak belum diisi, nilai tampil `-`.
