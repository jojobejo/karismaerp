5. CATATAN TEKNIS

  • Platform: Bram menggunakan MariaDB (XAMPP), sedangkan Yoga menggunakan MySQL 8.0+.
  • Collation: Terdapat perbedaan utf8mb4_general_ci vs utf8mb4_0900_ai_ci (Perbedaan versi ini tidak berdampak pada fungsionalitas).
  • Display Width: Perbedaan format penulisan int(11) vs int (Bawaan MySQL 8.0 menghilangkan padding width secara default, tidak berdampak fungsional).
  • Default Values: Perbedaan string literal seperti DEFAULT 0 vs DEFAULT '0' (Tidak berdampak fungsional).
  • Function: Perbedaan penulisan current_timestamp() vs CURRENT_TIMESTAMP (Tidak berdampak fungsional).
