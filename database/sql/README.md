# SQL migrasi per modul

Subfolder berisi skrip SQL berdasarkan modul. Keterangan perubahan, prasyarat, urutan, dan rollback dibaca pada [dokumentasi database](../../docs/database/) sebelum menjalankan skrip. Beberapa migrasi lama berada bersama dokumennya di `docs/database/<modul>/`.

Folder ini tidak berisi dump acuan atau backup. Penataan berkas tidak menjalankan SQL dan tidak mengubah skema database.
