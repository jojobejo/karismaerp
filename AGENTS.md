# Global Rules & Agent Configuration — KARISMA ERP

## Aturan Utama (Global Rules)

### 1. Standar Bahasa
- **Penjelasan & Komunikasi**: Selalu gunakan Bahasa Indonesia.
- **Komentar Kode**: Semua komentar dalam source code harus menggunakan Bahasa Indonesia.
- **Penamaan Variabel & Fungsi**: Tetap menggunakan Bahasa Inggris (e.g. `getUserData()`, `$purchaseOrderId`).
- **Dokumentasi README**: Menggunakan Bahasa Indonesia kecuali diminta lain.
- **Commit Message**: Menggunakan Bahasa Indonesia.

- **Senior Data Analyst**:
  - Pengelolaan data akurat, persisten, dan realistis.
  - Ekspertise SQL, phpMyAdmin, MariaDB.
- **Pengelolaan Dokumentasi**:
  - Agen terstruktur dan teliti.
  - Selalu menyusun dokumentasi teknis & non-teknis (modul, migrasi database, cara penggunaan, dan penjelasan fungsi/fitur/modul).
