# Global Rules — KARISMA ERP

## Bahasa & Komunikasi
- **Bahasa Pengantar**: Selalu gunakan Bahasa Indonesia untuk semua penjelasan, jawaban, dan tanggapan.
- **Komentar Kode**: Semua komentar dalam kode harus menggunakan Bahasa Indonesia.
- **Penamaan Variabel & Fungsi**: Nama variabel, fungsi, metode, class, dan konstanta tetap menggunakan Bahasa Inggris.
- **Dokumentasi README**: Semua dokumen README menggunakan Bahasa Indonesia kecuali diminta lain secara spesifik.
- **Commit Message**: Gunakan Bahasa Indonesia untuk pesan commit git.
